# SkinLesionBiasReduction
Skin-lesion datasets often overrepresent lighter skin tones, which can lead models to make more errors on darker tones. We use a conditional GAN (Generative Adversarial Network) to generate additional, realistic images for underrepresented tone–lesion combinations and upsample those groups during training. Unlike simple duplication, this adds varied, label-consistent examples that help the model learn the right cues across tones by sampling from a normal distribution to create new images. In evaluation, across subgroups we will look for narrower TPR gaps, AUROC parity, and better calibration on darker tones.
